# Aurelle salon platform

The runnable website is in [`aurelle`](aurelle/README.md). The source architecture remains in [`Salon Architecture`](Salon%20Architecture/README.md).

From `aurelle`, run `npm ci` once and `npm run dev`. Open [the studio workspace](http://localhost:3000) or [customer booking](http://localhost:3000/book). Choose **Explore the studio** to review the synthetic sample business. Run `npm run stop` to shut down cleanly.

See [implementation status](aurelle/docs/IMPLEMENTATION-STATUS.md) for implemented workflows and the remaining production architecture work.
